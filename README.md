# 🏃 Беговой календарь Москвы и МО (`running_calendar_moscow`)

Автоматически обновляемый календарь забегов, марафонов, полумарафонов, трейлов и легкоатлетических стартов в манеже по Москве и Московской области.

🌐 **Веб-версия (GitHub Pages):** [https://prartem476-dev.github.io/running_calendar_moscow/](https://prartem476-dev.github.io/running_calendar_moscow/)  
📅 **Подписка на iCal (`.ics`):** `https://prartem476-dev.github.io/running_calendar_moscow/moscow_running_events.ics`  
📦 **JSON база данных:** `https://prartem476-dev.github.io/running_calendar_moscow/moscow_running_events.json`

## ⚙️ Как это работает

1. **`moscow_running_parser.py`** — мульти-источниковый парсер, который собирает расписание забегов сразу с **13 площадок**:
   * **Беговое сообщество (`runc.run`)** — главная серия московских стартов в Лужниках, ЦСКА и по Садовому кольцу;
   * **ПроБЕГ (`probeg.org`)** — календарь шоссейных пробегов, марафонов и кроссов Москвы и МО;
   * **RussiaRunning (`reg.russiarunning.com`)** — крупнейшая платформа регистрации на забеги и марафоны России;
   * **Лига Героев (`heroleague.ru/calendar`)** — ЗаБег.РФ, Забег 2030, Гонка Героев в Москве и Алабино;
   * **Reg.Place (`reg.place`)** — агрегатор регистрации на беговые и трейловые старты;
   * **City Trail (`city-trail.ru`)** — серия парковых трейлов в Москве и Подмосковье от команды Wild Trail;
   * **DAB Running (`dab-running.ru`)** — горные забеги DAB Vertical Four Seasons в СК «Кант» (Москва);
   * **Медвежья гонка (`bearrace.ru`)** — забег с препятствиями на ОУСЦ «Планерная» (Химки);
   * **CRACE (`cracerun.ru`)** — фитнес-гонки с беговыми этапами и функциональными станциями;
   * **Лето ГТО (`gto-leto.sport.mos.ru`)** — фестивали ГТО и спортивные праздники Департамента спорта Москвы в Лужниках;
   * **MyRace (`myrace.info`)** — старты серии City Trail, X-Race, Кубок России Мастерс и др.;
   * **Mountain-Race (`mountain-race.ru`)** — специализированный календарь трейлов и кроссов Москвы и Подмосковья;
   * **5 вёрст & S95** — 90 еженедельных субботних парковых забегов на 5 км в парках Москвы и области.
2. **`index.html`** — интерактивный веб-календарь с фильтрацией по месяцам, дистанциям (`5 км`, `10 км`, `21.1 км`, `42.2 км`), покрытию (`Шоссе`, `Трейл / Грунт`, `Манеж`, `5 вёрст / S95`, `Новые в базе`, `Мои старты`), региону и кнопками добавления в Google/Apple/Яндекс Календарь.
3. **Инкрементальное пополнение базы (`moscow_running_parser.py` и `scripts/parse-events.mjs`)**:
   * При каждом запуске (`npm run parse` или `python moscow_running_parser.py`) парсер загружает существующую базу `moscow_running_events.json` и **дописывает к ней новые события** без потери ранее сохранённых стартов;
   * Новые анонсы получают метку времени `first_seen_at` и флаг `is_new: true`, а также синхронизируются с локальной SQLite БД (`running_calendar.db`).
4. **Личный кабинет бегуна без запроса персональных данных (152-ФЗ) + Гибридный API-сервер (`server.mjs` / `server.py`)**:
   * **Доступ по Токену / Email + Пароль:** генерация уникального анонимного ключа доступа вида `RUN-XXXX-XXXX-XXXX` (и опциональная привязка Email) + пароль с хешированием `PBKDF2-HMAC-SHA256` без сбора ФИО и телефона;
   * **Разделы кабинета:** «Мои старты» (выбор дистанции, статус покупки слота, стартовый номер BIB, целевое время с расчётом темпа, экспорт личного `.ics` календаря), «Мои результаты и рекорды (PB)» (автоматический расчёт темпа `мин/км` и личных рекордов на 5, 10, 21.1 и 42.2 км), «Новые старты в базе» (живой запуск парсера по кнопке) и перенос профиля между устройствами (`MRC1:...`);
   * Запуск локального сервера с SQLite API: `npm start` (или `python server.py`) → `http://127.0.0.1:3000`.
5. **`.github/workflows/scheduler.yml`** — GitHub Actions воркфлоу, который запускается автоматически каждый понедельник в **05:00 UTC (08:00 МСК)** или вручную через кнопку **Run workflow**, обновляет `.json` и `.ics` файлы и коммитит изменения обратно в репозиторий.
6. **Мобильное приложение Android для RuStore (`android/`, `rustore/`)** — обёртка на Capacitor 8 с полной офлайн-базой забегов и автоматической фоновой синхронизацией расписания с GitHub Pages:
   * Сборка подписанных `.apk` и `.aab`: `npm run android:release`
   * Готовые пакеты, иконка `512×512`, скриншоты `1080×1920` и тексты для `console.rustore.ru`: см. [`rustore/RUSTORE_GUIDE.md`](./rustore/RUSTORE_GUIDE.md).
