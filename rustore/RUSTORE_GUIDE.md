## 3. Команды для пересборки при выходе обновлений

1. При необходимости обновите базу стартов парсером:
   ```powershell
   python moscow_running_parser.py
   ```
2. Увеличьте `versionCode` (например, `2`) и `versionName` (например, `"1.0.1"`) в `android/app/build.gradle`.
3. Запустите сборку подписанных релизных пакетов `.apk` и `.aab`:
   ```powershell
   npm run android:release
   ```
   Готовые подписанные пакеты появятся в папке `rustore/builds/`.
